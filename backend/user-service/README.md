# User Service

`user-service` — сервис управления пользователями и аутентификацией в рамках системы **SemStore**.  
Отвечает за регистрацию пользователей, авторизацию, работу с JWT-токенами и управление адресами.

---

## Возможности

- Регистрация новых пользователей
- Аутентификация по email и паролю
- Генерация и обновление JWT access токена
- Валидация JWT токена
- Получение данных текущего пользователя
- Смена пароля пользователя
- Управление адресами пользователя:
  - создание адреса
  - получение списка адресов
  - обновление адреса
  - удаление адреса
